# 📊 Analytics and Dashboard Deep Dive

This report is structured into three main pages, each addressing a critical area of the supply chain: overall financial performance, product/inventory management, and supplier/logistics efficiency.

---

## 1. Overview Page 

### 📈 Dashboard Screenshot
![Overview Dashboard Page](https://github.com/ibrahimreda114/Depi_Final-Project/blob/main/images/Overview.png)

### 🔍 Analysis Focus
The Overview page serves as the executive summary, providing immediate high-level feedback on the financial health and general performance of the supply chain.

| Indicator | Description |
| :--- | :--- |
| **Top KPIs** | Total Revenue, Total Costs, Avg. Profit Margin (86.07%), and Inventory Availability (97.05%). |
| **Customer Segmentation** | Analyzes `Total Revenue by Customer demographics` (Male, Female, Non-binary) to understand market segments. |
| **Shipping Performance** | Compares `Total Revenue by Shipping carriers` (Carrier A, B, C), showing which carriers drive the most sales. |
| **Quality Snapshot** | `Avg of defect rates by Product type` to quickly identify if specific product categories (e.g., Skincare) have quality issues. |
| **Supplier Profit** | Table providing an immediate ranking of suppliers based on their average profit margin. |

## 2. Products Page 

### 📦 Dashboard Screenshot
![Products Dashboard Page](https://github.com/ibrahimreda114/Depi_Final-Project/blob/main/images/Products.png)

### 🔍 Analysis Focus
This page focuses on the physical flow of goods, inventory levels, and product-specific profitability, crucial for production and purchasing decisions.

| Indicator | Description |
| :--- | :--- |
| **Inventory KPIs** | Tracks Profits, Total Products Sold, current Stock Level, Orders Quantities, and Production Volumes. |
| **SKU Deep Dive** | Bar charts detailing `Orders quantities per SKU`, `stock levels per SKU`, and `total lead time per SKU`. This is vital for maintaining optimal re-order points. |
| **Profit Breakdown** | Donut chart showing the `Avg of profit margin % by product type`, isolating which categories (Cosmetics, Skincare, Haircare) are most profitable. |
| **Product Analysis Table** | Detailed matrix allowing drill-down into specific SKUs, listing their Costs, Revenue, Profit Margin, and Production Volumes side-by-side. |

## 3. Supplier & Shipping Page 

### 🚚 Dashboard Screenshot
![Supplier and Shipping Dashboard Page ](https://github.com/ibrahimreda114/Depi_Final-Project/blob/main/images/Supplier%20and%20shipping.png)

### 🔍 Analysis Focus
This page evaluates the efficiency of logistics and the reliability of external partners (Suppliers), directly impacting operational cost and quality.

| Indicator | Description |
| :--- | :--- |
| **Cost Summary** | Breaks down Total Costs into `Mfg Costs` (Manufacturing) and `Shipping costs`. |
| **Defect Rate Status** | A unique visual showing the percentage of `Pass`, `Fail`, and `Pending` inspection results, reflecting current quality control status. |
| **Transportation Modes** | Two key charts analyze `Total Revenue` vs. `Total Costs` by `Transportation modes` (Rail, Road, Air, Sea) to determine the most profitable and cost-effective shipping method. |
| **Supplier Reliability** |
| | - `Avg of defect rates by Supplier name`: Ranks suppliers by quality performance. |
| | - `Supplier's time Consistency`: Line chart tracking consistency over time (e.g., average lead time variation). |
